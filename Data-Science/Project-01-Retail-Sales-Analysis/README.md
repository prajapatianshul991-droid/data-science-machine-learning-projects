# Retail Sales Analysis

## Project Overview
This project analyzes retail sales data using Python to understand sales performance, product performance, customer ratings, and discount patterns.

## Dataset
- 500 rows
- 10 original columns
- Retail sales data

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Tasks Performed
1. Data inspection and exploration
2. Missing value handling
3. Duplicate checking
4. Feature engineering
5. Revenue analysis by product, category, city, and payment method
6. Customer rating analysis
7. Discount analysis
8. Data visualization
9. Net revenue calculation
10. Business insights

## Key Findings
- Electronics generated the highest category revenue: ₹21,04,609.
- Monitor was the highest revenue-generating product: ₹6,70,748.
- Noida recorded the highest city-wise revenue: ₹3,88,290.
- Total revenue before discounts: ₹36,35,152.
- Net revenue after discounts: ₹33,58,583.75.

## What I Learned
I practised data cleaning, data manipulation, exploratory data analysis, feature engineering, data visualization, and extracting business insights using Python.

## Conclusion
This project helped me understand how raw retail data can be analyzed and converted into meaningful business insights.
